# Página Sobre o Autor

Conteúdo da página profissional e biográfica de **Clovis Mariano da Costa**, nome autoral **Aeon Primevo**.

## Como instalar

1. Apague a pasta antiga `sobre-o-autor` do repositório local.
2. Descompacte este arquivo ZIP na raiz do repositório `Aeon-Primevo`.
3. Confirme que ficou assim:

```text
Aeon-Primevo/
└── sobre-o-autor/
    ├── index.html
    ├── styles.css
    ├── script.js
    ├── README.md
    └── assets/
        └── Curriculo_Clovis_Mariano_da_Costa.pdf
```

4. No GitHub Desktop, selecione a branch `pagina-sobre-o-autor`.
5. Faça commit e `Push origin`.

## Link no menu principal

No arquivo `index.html` da raiz, altere o link:

```html
<a href="#autor">Sobre o Autor</a>
```

para:

```html
<a href="sobre-o-autor/">Sobre o Autor</a>
```
